# Шаблоны сборочного чертежа и печатной платы для Draftsman

60 шаблонов листа `.DwsDot`, подготовленных на основе соседних исходных `GOSTBOM_*.SchDot`: по 30 для сборочного чертежа и печатной платы. В каждом наборе 20 обычных (первые и последующие листы) и 10 PZ.

- Суффикс `_AD`: сборочный чертеж, обозначение `=Обозначение СБ`, подпись «Сборочный чертеж» под наименованием.
- Суффикс `_PCB`: чертеж печатной платы, обозначение `=Обозначение_PCB`, наименование `=Наименование_PCB` из раздела GOSTBOM «Плата печатная ГОСТ 2.123». Без добавления «СБ», без подписи под названием и без дополнительных строк `Наименование2`/`Наименование3`.
- Масштаб первых листов обоих наборов: `=DocumentScale`, как в готовых шаблонах Draftsman. Нижняя правая ячейка оставлена пустой.

Размеры листов, линии рамок, штампы, шрифты и ссылки на параметры перенесены из исходников. В обозначении используется `=Обозначение СБ` вместо `=Обозначение_Код`, чтобы код схемы Э3 не попадал в сборочный чертеж. В наборе _AD под наименованием на первых листах размещена строка «Сборочный чертеж». Для номера первого листа применяется встроенный параметр Draftsman `=SheetNumber_OneSheet`.

Координаты сверены с установленными ГОСТ-шаблонами `Templates\Draftsman\A*_Form_*.DwsDot`: начало отсчета находится внизу слева. Исправлены ошибочная инверсия Y и расчет положения повернутых текстовых блоков. Проверено, что строка «Сборочный чертеж» на каждом первом листе находится в нижней области штампа.

## Применение и проверка

1. Скопируйте файлы `.DwsDot` в настроенную локальную папку шаблонов Altium или выберите нужный файл через настройки листа Draftsman.
2. Примените шаблон к листу Draftsman. Это шаблоны листа, без видов платы и сборки.
3. Проверьте размер, рамку, шрифты, поворот надписей и отображение параметров проекта. Нужен установленный шрифт Altium GOST Type A.
4. Проверьте обозначение и наименование согласно выбранному набору `_AD` или `_PCB`.

Файлы созданы преобразованием структуры исходников. После исправления упаковки все 60 файлов проверены штатным LZ4Stream и DataContractSerializer с типами данных и DataTypeResolver из установленного Draftsman AD24. Проверены чтение данных, структура XML, ссылки на объекты и замена полей. Используется поддерживаемый несжатый блок контейнера Legacy LZ4Stream. Открытие в редакторе, построение объектов листа и визуальная проверка в Altium не выполнялись по просьбе пользователя; отображение требует ручной проверки. Исходные `.SchDot` не изменены.
