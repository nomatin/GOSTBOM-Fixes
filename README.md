# GOSTBOM Fixes

Набор исправлений GOST BOM для Altium Designer: оформление перечня элементов, обозначения документов, имена файлов OutJob и выпуск документации для выбранного варианта проекта.

Комплект исправлений: **2026.10.16.3**.

## Возможности

- Заголовки разделов ПЭ3 по центру, с одинарным подчёркиванием, без жирного начертания и курсива. Оформление сохраняется при повторе заголовка на следующем листе.
- Пробел перед кодом ПЭ3 в штампе первого листа, последующих листов и листа регистрации изменений: `XXXX.XXXXX.XX ПЭ3`.
- Формирование параметра `Обозначение_Код` как `Обозначение + " " + Код_документа_SCH`.
- Создание и обновление `sheet_out_name` как `Наименование + " " + Обозначение_Код` при OK / Apply в GOST BOM → Project Properties.
- Имена Excel-файлов при выпуске через OutJob:
  - `Наименование XXXX.XXXXX.XX ПЭ3.xls` — перечень элементов;
  - `Наименование XXXX.XXXXX.XX ВП.xls` — ведомость покупных изделий;
  - `Наименование XXXX.XXXXX.XX.xls` — спецификация, без кода СП в имени.
- Выпуск ПЭ3, ВП и СП для текущего выбранного варианта Altium с исключением компонентов Not Fitted. Позиции спецификации записываются только в выбранный вариант ActiveBOM; настройки BOM восстанавливаются после работы.
- Суффиксы исполнений в обозначениях и именах файлов. Базовый параметр `Обозначение` проекта сохраняется.

### Суффиксы исполнений

Номер исполнения определяется по непрерывной последовательности цифр в конце имени варианта. Пробелы по краям имени игнорируются.

| Имя варианта | Суффикс | Пример обозначения |
|---|---|---|
| `Вариант1` | `-01` | `XXXX.XXXXX.XX-01` |
| `Вариант001` | `-01` | `XXXX.XXXXX.XX-01` |
| `Исполнение12` | `-12` | `XXXX.XXXXX.XX-12` |
| `Вариант100` | `-100` | `XXXX.XXXXX.XX-100` |
| Без цифр в конце | `-XX` | `XXXX.XXXXX.XX-XX` |
| Вариант с номером `0`, базовый состав или отсутствие вариантов | Без суффикса | `XXXX.XXXXX.XX` |

Суффикс учитывается в `Обозначение_Код` и `sheet_out_name` при OK / Apply в Project Properties.

## Требования и совместимость

- Windows и Windows PowerShell 5.1 или новее.
- Установленные Altium Designer и расширение GOST BOM.
- Совместимая сборка расширения: установщик сверяет SHA-256 двух заменяемых DLL и 13 зависимостей с включённым списком поддерживаемых файлов.

Поддерживаются исходная сборка и промежуточные исправленные сборки, перечисленные в установщике. При неизвестной сборке или несовместимых зависимостях установка останавливается до замены DLL. Номер версии Altium и GUID каталога могут отличаться; совместимость определяется по файлам расширения.

Интернет, компилятор и установка Altium SDK для запуска не требуются.

## Установка

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив либо клонируйте репозиторий.
2. Оставьте `Install-GOSTBOM-Fixes.cmd`, `GOSTBOM2.dll` и `Vedomost.dll` в одной папке.
3. Сохраните проекты и закройте Altium Designer.
4. Запустите `Install-GOSTBOM-Fixes.cmd` двойным щелчком. Подтвердите запрос прав администратора, если он появится, и дождитесь сообщения о результате.
5. Откройте Altium → GOST BOM → Project Properties, нажмите **OK / Apply** и сохраните проект.
6. Заново сформируйте документы.

Если Windows заблокировала скачанный архив, откройте его свойства и выберите «Разблокировать» перед распаковкой.

CMD содержит код установщика. При запуске он создаёт временную папку со сценарием PowerShell и копиями DLL, а после завершения удаляет её. Отдельный файл PS1 не требуется. Политика выполнения PowerShell задаётся только для запускаемого процесса.

### Проверка без установки

Откройте командную строку в папке с CMD и выполните:

```bat
Install-GOSTBOM-Fixes.cmd -CheckOnly
```

Проверка не изменяет установленное расширение и не требует прав администратора.

### Несколько установок Altium или нестандартная папка

Автоматический поиск выполняется в `%ProgramData%\Altium\*\Extensions\GOST BOM`. Если совместимых установок несколько, укажите нужную папку явно:

```bat
Install-GOSTBOM-Fixes.cmd -ExtensionPath "C:\ProgramData\Altium\Altium Designer {GUID}\Extensions\GOST BOM"
```

Замените путь на фактический. Параметр `-ExtensionPath` также поддерживается при проверке и откате:

```bat
Install-GOSTBOM-Fixes.cmd -CheckOnly -ExtensionPath "C:\ProgramData\Altium\Altium Designer {GUID}\Extensions\GOST BOM"
```

## Резервная копия и откат

Перед заменой установщик сохраняет текущие DLL и их контрольные суммы:

```text
<папка GOST BOM>\GOSTBOM-backups\<дата-время-идентификатор>
```

Путь к резервной копии выводится в сообщении о результате. Повторная установка полностью исправленного комплекта ничего не меняет.

Для отката закройте Altium и выполните:

```bat
Install-GOSTBOM-Fixes.cmd -RestoreFrom "C:\путь\к\резервной-копии"
```

При необходимости добавьте `-ExtensionPath`. Установщик проверяет принадлежность копии выбранной установке, состав файлов и контрольные суммы. Откат возвращает состояние DLL перед соответствующей установкой.

Если замена одной из DLL завершается ошибкой, установщик пытается автоматически восстановить исходные файлы и сообщает результат.

## Особенности работы

- После установки ранее созданные Excel-файлы необходимо сформировать заново.
- `sheet_out_name` обновляется при OK / Apply в GOST BOM → Project Properties. После смены варианта снова выполните это действие и сохраните проект.
- Выбор варианта выполняется в проекте Altium перед выпуском. Переключение вариантов внутри OutJob не добавляется.
- Установщик заменяет две DLL. Файлы проектов, настройки `.OutJob`, библиотеки компонентов и Excel-шаблоны при установке не редактируются.
- Имена PDF-файлов схемы Э3 этим комплектом не изменяются.
- Базовый состав и вариант с номером `0` имеют одинаковое обозначение. Варианты без цифр в конце имени получают одинаковый суффикс `-XX`. При совпадении имени и папки вывода документы могут перезаписываться.
- Обновление или переустановка GOST BOM может заменить исправленные DLL. Для новой сборки повторно проверьте совместимость.
