# Все выполненные правки GOST BOM одним скриптом

Выпуск: 16 октября 2026 года, версия 2026.10.16.3.

Для переноса нужны **Install-GOSTBOM-Fixes.cmd**, **GOSTBOM2.dll** и **Vedomost.dll** из этой папки. Держи все три файла рядом. Интернет, полный Altium SDK, компилятор и Mono.Cecil для установки не нужны.

## Что устанавливается

1. Заголовки разделов ПЭ3: без жирности, без курсива, с одинарным подчёркиванием. Выравнивание по центру сохранено. Повтор заголовка на следующем листе оформляется так же.
2. Пробел перед ПЭ3 в обозначении штампа на первом листе, последующих листах и листе регистрации изменений: `XXXX.XXXXX.XX ПЭ3`.
3. Пробел в `Обозначение_Код`: `Обозначение + " " + Код_документа_SCH`.
4. Параметр проекта `sheet_out_name`: `Наименование + " " + Обозначение_Код`. Создаётся и пересчитывается при каждом OK / Apply в окне GOST BOM → Project Properties после обновления `Обозначение_Код`.
5. Имена Excel-файлов GOST BOM через OutJob:
   - `Наименование Обозначение ПЭ3.xls`;
   - `Наименование Обозначение ВП.xls`;
   - `Наименование Обозначение.xls` — спецификация без СП.
6. Выпуск ПЭ3, ВП и СП только для текущего выбранного варианта проекта Altium. Неустановленные компоненты (Not Fitted) исключаются. Позиции спецификации возвращаются только выбранному варианту ActiveBOM; настройки BOM восстанавливаются после работы.
7. Суффикс исполнения в обозначениях и именах файлов: `1 → -01`, `2 → -02`, `12 → -12`, `100 → -100`. Для нуля, отсутствия вариантов и базового состава суффикса нет. Номер берётся из непрерывной последовательности цифр в конце имени: `Вариант1 → -01`, `Исполнение12 → -12`, `Вариант001 → -01`. Пробелы по краям имени игнорируются. Если цифр в конце нет, используется `-XX`. Базовое `Обозначение` в проекте не изменяется. При OK / Apply в Project Properties суффикс учитывается в `Обозначение_Код` и `sheet_out_name`.

## Совместимость

Скрипт переносит проверенные исправленные `GOSTBOM2.dll` и `Vedomost.dll`. Он поддерживает ту же исходную сборку GOST BOM, которую мы разобрали, и известные промежуточные версии наших правок.

Сверяются SHA-256 обеих DLL и 13 зависимостей. Версия Altium и GUID папки могут отличаться, но сами файлы расширения и проверяемые зависимости должны быть совместимыми. При неизвестной сборке скрипт остановится, не заменяя DLL. Это установщик проверенного комплекта, а не универсальный патчер любой будущей версии GOST BOM.

На другом компьютере GOST BOM уже должен быть установлен. Нужны Windows и Windows PowerShell 5.1 или новее.

## Запуск

1. Перенеси CMD и обе DLL из этой папки на другой компьютер.
2. Сохрани проекты и закрой Altium.
3. Запусти **Install-GOSTBOM-Fixes.cmd** двойным щелчком или выполни из командной строки:

```bat
Install-GOSTBOM-Fixes.cmd
```

Параметр ExecutionPolicy действует только для этого запуска. Скрипт сам запросит повышение прав Windows, если требуется. Итог показывается отдельным сообщением; путь к резервной копии также выводится.

4. Открой Altium. В GOST BOM → Project Properties нажми OK / Apply и сохрани проект, чтобы создать или обновить `sheet_out_name`. Затем заново сформируй документы.

Если Windows пометила скачанный файл как заблокированный, в его свойствах нажми «Разблокировать» перед запуском.

## Если установок Altium несколько

Скрипт ищет расширение в `%ProgramData%\Altium\*\Extensions\GOST BOM`. Если найдена одна совместимая установка, выберет её. При нескольких подходящих установках нужно явно указать нужную папку:

```bat
Install-GOSTBOM-Fixes.cmd -ExtensionPath "C:\ProgramData\Altium\Altium Designer {GUID}\Extensions\GOST BOM"
```

Подставь реальный GUID. Для нестандартного расположения расширения используй этот же параметр.

## Проверка без установки

```bat
Install-GOSTBOM-Fixes.cmd -CheckOnly
```

Проверка не изменяет файлы и не требует повышения прав. Для конкретной установки можно добавить `-ExtensionPath`.

## Резервная копия и откат

Перед заменой скрипт сохраняет обе текущие DLL и их контрольные суммы в отдельную папку:

```text
<папка GOST BOM>\GOSTBOM-backups\<дата-время-идентификатор>
```

Сохраняются именно файлы, которые были перед запуском: если часть правок уже стояла, откат вернёт это состояние. Повторный запуск на полностью исправленной версии ничего не меняет.

Для отката закрой Altium и выполни:

```bat
Install-GOSTBOM-Fixes.cmd -RestoreFrom "ПОЛНЫЙ_ПУТЬ_К_РЕЗЕРВНОЙ_КОПИИ"
```

При нескольких установках добавь `-ExtensionPath`. Резервная копия должна принадлежать выбранной установке; скрипт проверит её путь, состав и контрольные суммы.

Если замена одной из DLL завершается ошибкой, установщик пытается автоматически вернуть исходные файлы и сообщает результат.

## Что важно после установки

- Ранее созданные Excel-файлы нужно сформировать заново.
- `sheet_out_name` обновляется при OK / Apply в окне GOST BOM, а не при любой внешней правке проекта.
- Настройки `.OutJob`, параметры проектов, библиотеки компонентов и Excel-шаблоны установщик не редактирует.
- Имена PDF-файлов схемы Э3 этим комплектом не меняются.
- Вариант выбирается в самом проекте Altium перед выпуском; переключения вариантов внутри OutJob не добавлялось. После смены варианта нажми OK / Apply в GOST BOM → Project Properties и сохрани проект для обновления специальных строк штампа схемы.
- Без вариантов и вариант `0` используют одинаковое базовое обозначение; имена без цифр на конце получают одинаковый суффикс `-XX`. При одинаковых наименовании и папке вывода такие файлы могут перезаписывать друг друга.
- Обновление или переустановка GOST BOM может заменить исправленные DLL. Если новая сборка неизвестна, установщик откажется применять старый комплект.
