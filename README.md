# GOSTBOM Fixes

Исправления GOST BOM для Altium Designer: оформление документов, имена файлов OutJob, поддержка выбранного варианта проекта и работа без печатной платы.

## Быстрая установка

1. Скачайте репозиторий: **Code → Download ZIP**, затем распакуйте архив.
2. Сохраните проекты и закройте Altium Designer.
3. Запустите **Install-GOSTBOM-Fixes.cmd** из распакованной папки. Если появится запрос прав администратора, подтвердите его.
4. Дождитесь сообщения об успешной установке.
5. Откройте Altium → **GOST BOM → Project Properties**, нажмите **OK / Apply** и сохраните проект.
6. Сформируйте документы заново, чтобы применить исправления.

## Что исправлено

### Оформление и реквизиты

- Заголовки разделов ПЭ3 выровнены по центру, с одинарным подчёркиванием, без жирного начертания и курсива. Оформление сохраняется при повторении заголовка на следующем листе.
- Перед кодом ПЭ3 добавлен пробел в штампах первого и последующих листов, а также листа регистрации изменений.
- Параметр `Обозначение_Код` формируется как `Обозначение + " " + Код_документа_SCH`.
- Параметр `sheet_out_name` обновляется при **OK / Apply** в Project Properties: `Наименование + " " + Обозначение_Код`.

### Выпуск через OutJob

| Документ | Имя Excel-файла |
|---|---|
| Перечень элементов | `Наименование XXXX.XXXXX.XX ПЭ3.xls` |
| Ведомость покупных изделий | `Наименование XXXX.XXXXX.XX ВП.xls` |
| Спецификация | `Наименование XXXX.XXXXX.XX.xls` |

Для спецификации код СП в имя файла не добавляется. Имена PDF-файлов схемы Э3 этим комплектом не изменяются.

### Варианты исполнения

ПЭ3, ВП и СП формируются для текущего выбранного варианта Altium с исключением компонентов **Not Fitted**. Позиции спецификации записываются в выбранный вариант ActiveBOM; настройки BOM восстанавливаются после работы.

Суффикс исполнения добавляется в обозначения и имена файлов. Базовый параметр `Обозначение` проекта сохраняется. Номер определяется по цифрам в конце имени варианта; пробелы по краям игнорируются.

| Имя варианта | Суффикс |
|---|---|
| `Вариант1`, `Вариант001` | `-01` |
| `Исполнение12` | `-12` |
| `Вариант100` | `-100` |
| Имя без цифр в конце | `-XX` |
| Вариант с номером `0`, базовый состав или отсутствие вариантов | Без суффикса |

### Работа без печатной платы

Добавлены два способа отключить всплывающее предупреждение «В проекте отсутствует плата!»:

- **«Разрешить работу без печатной платы»** — галочка внизу окна GOSTBOM Properties, на уровне кнопок.
- **«Больше не показывать в этом проекте»** — галочка в самом предупреждении.

Оба флажка управляют одной настройкой текущего проекта. Она учитывается и при запуске через OutJob. **После изменения сохраните проект**, чтобы настройка сохранилась после повторного открытия.

Чтобы вернуть предупреждение, снимите галочку в Properties и сохраните проект. Если плата появится в проекте, она будет обрабатываться обычным образом. Размер окна предупреждения автоматически подбирается под содержимое.

## Требования и совместимость

- Windows с Windows PowerShell 5.1.
- Установленные Altium Designer и GOST BOM.
- Поддерживаемая сборка DLL расширения и совместимые зависимости.

Установщик проверяет контрольные суммы файлов. Поддерживаемые сборки перечислены внутри CMD; совместимость определяется по файлам расширения, а не только по номеру версии Altium. При неизвестной сборке установка останавливается до замены файлов.

Для установки не требуются интернет, компилятор или отдельная установка Altium SDK.

### Проверка без установки

Откройте командную строку в папке комплекта:

```bat
Install-GOSTBOM-Fixes.cmd -CheckOnly
```

Проверка не изменяет установленное расширение и не требует прав администратора.

### Выбор папки Altium

Автоматический поиск выполняется в `%ProgramData%\Altium\*\Extensions\GOST BOM`. При нескольких установках или нестандартном расположении укажите путь явно:

```bat
Install-GOSTBOM-Fixes.cmd -ExtensionPath "C:\ProgramData\Altium\Altium Designer {GUID}\Extensions\GOST BOM"
```

Замените путь на фактический. Параметр `-ExtensionPath` можно сочетать с `-CheckOnly` и `-RestoreFrom`.

## Резервная копия и откат

Перед установкой сохраняются предыдущие файлы и их контрольные суммы в папке расширения:

```text
GOSTBOM-backups\<дата-время-идентификатор>
```

Путь к копии выводится после установки. Повторный запуск на полностью обновлённом комплекте ничего не меняет.

Чтобы вернуть состояние до установки, закройте Altium и выполните:

```bat
Install-GOSTBOM-Fixes.cmd -RestoreFrom "C:\путь\к\резервной-копии"
```

При необходимости добавьте `-ExtensionPath`. Если `GostBomNoPcb.dll` до установки отсутствовала, откат удалит её. При ошибке замены файлов установщик пытается автоматически восстановить исходное состояние и сообщает результат.

Обновление или переустановка GOST BOM может заменить исправленные DLL. После этого снова выполните проверку совместимости.
